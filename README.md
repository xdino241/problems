# Problems

My personal practice repo for SQL and algorithms. I'm a third-year Computer Science student (Data Science specialization) and I use this repo to build consistency and track progress.

## What's inside

- **`sql/`**: LeetCode SQL 50 study plan, plus extra practice from DataLemur and PostgreSQL Exercises.
- **`algorithms/`**: NeetCode 150, solved in Python.

## How I work

Each solution has a link to the problem, the main topic, and a short note on the approach. When I find a second way to solve something (e.g. a window function instead of a self-join), I add it below the main solution and compare them.
